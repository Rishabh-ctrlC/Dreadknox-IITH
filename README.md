# Dreadknox - Smart Campus Solutions for IITH

## Project Overview
Dreadknox is a web-based smart campus solution built for the Lambda Hackathon (MILAN 2026)[cite: 1]. It serves as a centralized, hostel-based directory to store and share information about pod-mates at IIT Hyderabad. By enabling students to quickly locate peers, check their academic branches, and find emergency contacts, Dreadknox fosters a more connected, accessible, and user-friendly campus environment[cite: 1].

## Features
* **Live Directory Search:** Instantly search for students by name, roll number, or pod location.
* **Block Filtering:** Filter students specifically by their hostel blocks (e.g., Lambda, Epsilon).
* **Dark Mode UI:** A fully responsive, modern interface with a built-in theme toggle for a better user experience.
* **No-Backend Setup:** Runs completely in the browser using lightweight front-end technologies.

## Technology Stack
* HTML5
* CSS3
* Vanilla JavaScript

## Local Setup Instructions
Anyone can set up and run this project locally by following these steps[cite: 1]:
1. Clone or download this repository to your local machine as a ZIP file and extract it.
2. Ensure you have a standard web browser installed (e.g., Google Chrome, Firefox, Safari).
3. Navigate to the extracted folder containing the project files.
4. Double-click the `index.html` file to open it directly in your web browser. 
5. The application is entirely frontend-based, so no servers, package managers, or additional database installations are required.
